# 产品与交互说明

> 本文以**小程序当前实际 UI** 为准，功能范围与界面一一对应；未在界面上出现的能力不视为本期范围。

## 1. 设计方向

关键词：温暖、清爽、轻量、可信赖、家庭厨房。

视觉系统采用 shadcn 风格的克制设计：浅色背景、清晰边框、圆角卡片、统一间距、状态色与轻量阴影。首页使用食材色块与较大的菜品卡片，减少表格感。

### 颜色 Token

| Token | 色值 | 用途 |
|---|---|---|
| background | `#F7F7F2` | 全局背景 |
| surface | `#FFFFFF` | 卡片/弹层 |
| primary | `#245B45` | 主操作、品牌色 |
| primary-soft | `#E8F0E9` | 浅绿底 |
| text | `#1D2923` | 主文字 |
| muted | `#77827B` | 次级文字 |
| border | `#E8EAE4` | 分隔线 |
| warning | `#D18A35` | 缺少配料 |
| danger | `#C75D4D` | 删除/错误 |

## 2. 页面结构

### 全局

- 首页左侧为竖向分区栏，四个分区：**今日推荐 / 食材库存 / 菜品食谱 / 今日宜吃**；切换分区时回到页面顶部。
- 底部固定 Dock：**首页 / 我的**，两个 Tab 常驻同一页面实例，切换无路由跳转。
- 后端不可用或处于游客模式时，首页右上角显示「本地演示」标签。

### 今日推荐

1. 问候语「你好，{昵称}」+ 中文日期 + 「我的家」胶囊（点击切到「我的」并直接打开家庭空间面板）。
2. Hero 卡：主标题、「看看今日推荐」按钮（跳转今日宜吃）、插画、底部统计「已找到 N 道库存可直接开做的菜」。
3. 「最合适的一餐」：取今日宜吃中**食材齐全**的榜首；若无齐全项，显示空态文案。

### 食材库存

1. 标题右侧：「刷新」（主动拉取家庭成员的最新数据）与「添加食材」。
2. 分类药丸筛选：全部 / 蔬菜 / 肉类 / 水产 / 蛋奶 / 主食 / 调味品 / 其他。
3. 食材卡片：一行三个正方形磁贴，内容为**分类图标 + 名称 + 分类**；不显示数量与单位。
4. 点击卡片编辑名称/分类；右上角 × 删除（二次确认）。

### 菜品食谱

1. 两列卡片：插画、序号、难度、菜名、时长、配料数。
2. 点击进入详情弹窗（只读）：库存匹配情况（已有必选 / 缺少必选 / 可选配料）、准备食材、制作步骤、底部「已制作，记一笔」。
3. **前端不提供新增/删除菜谱入口**，菜谱由服务端或数据脚本维护。

### 今日宜吃

1. 推荐列表：按「必选齐全优先 + 组内评分」排序，逐条显示插画、菜名、难度与时长、`食材齐全` / `缺少 N 项`、已具备配料数与缺少明细。
2. 点击进入与菜谱详情相同的弹窗（含匹配情况）。
3. 列表为空时显示「还没有可推荐的菜谱」。

### 我的

1. 顶部标题「我的小厨房」与副标题。
2. 资料卡：emoji 头像选择、昵称编辑、角色徽标（家庭厨房管理员 / 家庭厨房成员）。
3. 家庭空间：显示当前家庭名与角色；点击打开家庭面板（见 3.6）。
4. 做菜记录：表格展示 **序号 / 做菜人 / 菜品 / 时间**，家庭成员共享；每页 20 条，「加载更多」继续追加。
5. 推荐与通知：**每日推荐**开关 + **推荐时间**选择；关闭开关时时间选择被禁用并置灰。
6. 其他：关于、退出登录（游客模式下变为「登录并同步数据」）。

## 3. 关键交互

### 3.1 食材维护

- 新增/编辑只填**名称 + 分类**；新增记录默认数量 1 个（数量字段保留但不参与判定）。
- 名称重复时提示「库存里已有同名食材」，不合并。
- 删除需二次确认，文案明确「删除后，这项食材将从库存列表中移除」。
- 「刷新」成功后提示「已刷新最新库存与推荐」；离线时提示「当前为本地数据」。

### 3.2 库存分类

切换筛选项只改变可见列表，不修改原始库存；列表顺序始终按分类顺序（蔬菜→肉类→水产→蛋奶→主食→调味品→其他）排列。

### 3.3 推荐判定

- **有就算有**：库存中存在同名食材即视为满足，不比较数量与单位。
- 必选配料齐全的菜品排在缺料菜品之前；同等级内按覆盖率、难度适配、近期重复惩罚、可选配料匹配度排序。

### 3.4 菜谱详情与已制作

- 详情展示难度、时长、描述、库存匹配、准备食材与步骤。
- 「已制作，记一笔」写入家庭做菜记录，参与近期重复惩罚，并出现在「我的 → 做菜记录」。

### 3.5 分享与邀请

- 管理员在家庭面板生成 6 位邀请码（24 小时内有效，可多人使用）。
- 可复制邀请码或「分享给微信好友」；分享卡片路径携带 `invite` 参数，对方点开后自动登录并加入该家庭。
- 成员不能邀请或移除他人。

### 3.6 家庭面板

- 顶部：家庭名称、成员数、我的角色（管理员 / 成员）。
- 成员列表：头像、昵称、（我）标识、角色；管理员可移除非管理员成员。
- 邀请码区（仅管理员）：生成、展示、复制、重新生成、分享给好友。
- 加入其他家庭：输入邀请码加入。
- 家庭成员数 > 1 时出现「切换家庭」，切换后库存/推荐随之刷新。

### 3.7 游客模式

退出登录后清除本机登录态并切换为本地演示数据，顶部显示「本地演示」；「登录并同步数据」可恢复。

### 3.8 离线兜底

后端不可用时使用本地缓存数据；离线期间新增的食材会在恢复连接后自动补推到后端。

## 4. 推荐标签约定

- `食材齐全`：全部必选配料均存在于库存。
- `缺少 N 项`：有 N 种必选配料不在库存中。
- 可选配料缺少只做提示，不影响「食材齐全」判定。

## 5. 适配原则

- 面向 375–430px 常见手机宽度设计。
- 首页模块纵向排列，卡片内容允许换行；食材卡片固定为正方形三列布局。
- 弹层使用底部 Sheet，按钮触控高度至少 44px。
- 重要状态同时用文字与颜色表达，避免仅依赖颜色。
