# 产品与交互说明

## 1. 设计方向

关键词：温暖、清爽、轻量、可信赖、家庭厨房。

视觉系统采用 shadcn 风格的克制设计：浅色背景、清晰边框、圆角卡片、统一间距、状态色与轻量阴影。与传统管理后台不同，首页使用食材色块和较大的菜品卡片，减少表格感。

### 颜色 Token

| Token | 色值 | 用途 |
|---|---|---|
| background | `#F7F7F2` | 全局背景 |
| surface | `#FFFFFF` | 卡片/弹层 |
| primary | `#245B45` | 主操作、品牌色 |
| primary-soft | `#E8F0E9` | 浅绿底 |
| text | `#1D2923` | 主文字 |
| muted | `#77827B` | 次级文字 |
| border | `#E8EAE4` | 分隔线 |
| warning | `#D18A35` | 缺少配料 |
| danger | `#C75D4D` | 删除/错误 |

## 2. 页面结构

### 首页

1. 顶部品牌区：问候语、日期、当前家庭标识。
2. 今日推荐主视觉：摘要和查看推荐按钮。
3. 食材库存：分类筛选、数量概览、小卡片、新增入口。
4. 菜品食谱：横向大卡片、难度、预计时长、添加菜谱入口。
5. 今日宜吃列表：按库存匹配优先级排列，显示匹配状态。
6. 底部导航：首页、我的。

### 我的

1. 个人资料卡：预设头像、昵称编辑。
2. 家庭管理入口：一期显示规划状态，二期接入家庭成员。
3. 通知设置：自动/手动、每日推荐开关。
4. 关于和退出登录。

## 3. 关键交互

- 新增食材：点击“添加”，输入名称、分类、数量和单位，确认后立即刷新卡片和推荐。
- 库存分类：切换筛选项只改变可见列表，不修改原始库存。
- 菜谱详情：展示菜品、难度、时长、必选/可选配料、步骤。
- 新增菜谱：输入菜名和配料；本期快速录入支持以顿号/逗号分隔必选与可选配料，服务端模型保留结构化字段。
- 推荐详情：用不同状态标记库存已有、缺少必选、缺少可选。
- 已制作：记录当前时间与菜谱，推荐结果对该菜品施加近期重复惩罚。
- 删除：二次确认，避免误删。

## 4. 推荐标签约定

- `食材齐全`：全部必选配料数量满足。
- `缺少 N 项`：有 N 种必选配料不足/缺少。
- 可选配料缺少只显示提示，不影响“食材齐全”状态。

## 5. 适配原则

- 面向 375–430px 常见手机宽度设计。
- 首页模块纵向排列，卡片内容允许换行。
- 弹层使用底部 Sheet，按钮触控高度至少 44px。
- 重要状态同时用文字与颜色表达，避免仅依赖颜色。
